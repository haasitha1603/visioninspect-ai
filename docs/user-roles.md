# User Roles

## Quality Engineer

The Quality Engineer is responsible for performing and managing product image inspections.

### Milestone 1 capabilities

- Login to the platform
- Access the inspection dashboard
- Upload product images
- Create inspection records
- View inspection information
- View inspection history

## Factory Supervisor

The Factory Supervisor is responsible for monitoring inspection activities and reviewing inspection information.

### Milestone 1 capabilities

- Login to the platform
- Access the inspection dashboard
- View inspection records
- View inspection history
- Monitor inspection information

## Authentication and Authorization

The system will authenticate users before granting access to protected platform features.

Role-based authorization will determine which operations are available to Quality Engineers and Factory Supervisors.
